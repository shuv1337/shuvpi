# Shuvpi 1.0.0

Shuvpi 1.0.0 rebases the fork on upstream Pi 1.0.0 and carries forward the selected Shuvpi behavior. The executable remains `shuvpi`, published as `@shuv1337/shuvpi-coding-agent` with its production dependencies.

## Changes

- Uses Shuvpi package names, configuration, authentication and session storage under `~/.shuvpi/agent`, with `SHUVPI_*` environment overrides. Existing `~/.pi` state is not imported automatically.
- Adds durable workflows backed by a detached local owner, SQLite storage and a replay journal. Work can complete after the chat process exits; reopening the chat delivers completion results once.
- Integrates native MCP and QuickJS codemode with captured tool and trust policies. Recovery stops when replay or policy compatibility cannot be established.
- Retains the selected provider, model, reasoning and history behavior, background jobs, subagent adapters, skills, shell mode and UI customizations.
- Provides optional extension entrypoints, Node package installation, a local Bun binary builder, npm update checks and release tooling for the Shuvpi dependency closure.

## Migration

Pi 1.0 changes the extension and SDK interfaces. Review the shipped extension, SDK, environment-variable and ported-extension documentation when moving custom integrations. Configure providers in the Shuvpi state directory. Legacy package import aliases are available to extensions where documented; they do not make old configuration variables or storage paths active.

## Validation and distribution

Repository checks and non-e2e tests passed. Isolated Linux Node and Bun artifacts were tested for interactive reload, native MCP and codemode, background completion, one-time receipt delivery and SQLite recovery after process termination. Release smoke tests additionally exercise real provider replies in print and interactive mode.

The npm release publishes the CLI and its nine-package production closure. Development-only workspaces are excluded. GitHub release notes follow successful npm publication. CI does not publish prebuilt binaries for other operating systems in this release.

This is a local coding agent with the permissions of its user, not an operating-system sandbox. Existing upstream released changelog sections and credits are preserved.
